# Онлайн-прослушивание плейлистов и автоматический подбор

## Причина прежней остановки

HomeFeed разрешал только исходную ссылку. Отказ сервиса, отсутствие браузерной сессии или таймаут завершали операцию без обращения к другим источникам. Ошибка уже открытого QMediaPlayer также не запускала замену. В библиотеке кнопка воспроизведения отсутствующего файла открывала диалог скачивания. У «Моей волны» чаще оставались актуальные данные потока, поэтому этот путь мог работать отдельно от импортированной коллекции.

## Изменения

- Общий путь для подборок главной, рекомендаций и треков библиотеки. Свежий поток пробуется напрямую; иначе разрешается исходная запись и параллельно ищутся альтернативы во всех включённых источниках автоподбора. Для поиска доступны YouTube, SoundCloud, Internet Archive, Zaycev.net и Hitmo. Исходные VK/Яндекс остаются первыми вариантами, если доступна сессия.
- Исходному источнику даётся 4,5 секунды преимущества. При наличии подходящего кандидата выполняется переход к нему; получение отдельного URL ограничено 15 секундами, ожидание буферизации — 20 секундами. Неответивший провайдер не блокирует другие результаты. Одновременно ищут максимум три провайдера; для одного сервиса разрешается до трёх подходящих попыток.
- Рейтинг учитывает совпадение названия и исполнителя, версию и близость длительности. Неизвестная длительность допустима только при полном совпадении текста. После открытия проверяется фактическая длительность: фрагменты и записи другой длины также запускают следующий вариант. Если подходящего потока нет, отображается ошибка и остаётся ручной выбор.
- URL, ключ и идентификатор очереди относятся к оригинальному треку. Альтернативный URL используется для получения аудио и Referer, название/альбом/оценки/плейлисты в базе не подменяются. Локальная обложка сохраняется. Поток работает без добавления задачи скачивания.
- В строках отсутствующих файлов есть «Онлайн», отдельное действие скачивания и пункт меню «Слушать онлайн». Кнопка на обложке и двойной щелчок тоже запускают прослушивание. Очередь включает текущую видимую выборку плейлиста/поиска, а не один трек. Подключение можно отменить; отменённые результаты не запускают воспроизведение позже.

## Проверка

Обе сборки AuroraPlayer прошли. Четыре целевых проверки QtTest прошли: подбор последовательно пытается получить потоки из двух включённых сервисов при отказе, отмена останавливает процесс, несоответствующие версии отбрасываются, очередь сохраняет отсутствующие файлы и треки без исходной ссылки. В сценарии перебора используются локальные фиктивные ответы загрузчика: нет реальных запросов сервисам, скачанных файлов и изменения записей библиотеки.

Запуск обеих сборок в отдельных временных XDG-каталогах со сценами cosmos и bonsai: четыре запуска с кодом 0 и QML warnings: 0. Реальные онлайн-аудиопотоки и аккаунты в этой среде не проверялись; доступность каждого сайта не подтверждается этими тестами. Проверка удобства дизайна не проводилась.
