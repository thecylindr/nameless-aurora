# Главная и рекомендации

На главной есть три периода: «На сегодня», «На 3 дня» и «На этой неделе». В каждом — общая подборка и до шести миксов по собственным плейлистам. Карточка открывает состав; кнопка воспроизведения запускает отдельную очередь из файлов и поддерживаемых онлайн-записей. У каждой записи в составе есть своя кнопка прослушивания; поиск другого источника вынесен отдельно. Окно состава остаётся открытым при прослушивании.

В подборках участвуют все записи медиатеки, включая импортированные и непрослушанные. Оценки и непрослушанные записи получают бонус; пропуски снижают приоритет. Сначала отбираются разные исполнители, затем заполняются оставшиеся места. Число прежних прослушиваний не даёт накапливаемого бонуса. В общей подборке до 18 / 36 / 60 треков соответственно. При маленькой коллекции подборки могут пересекаться.

Ротация определяется датой и ID трека: день, последовательные трёхдневные интервалы, неделя с понедельника. Переключение вкладки не делает запросов к базе. Импорт, удаление, изменение оценок или истории обновляют подборки с объединением частых сигналов в один пересчёт. После полуночи дата проверяется раз в минуту. Фильтр и поиск библиотеки не ограничивают подборки и не меняют их играющую очередь.

## Названия и настройки

Служебные названия вроде «Главная» и «Импортированный плейлист» превращаются в личные миксы с исполнителем, «Мне нравится» — в «Любимое сегодня / на три дня / на неделю». Исходное имя показывается в подписи и остаётся в библиотеке. Длинные названия занимают две строки; полное доступно в подсказке.

«Настроить» сохраняет баланс нового/любимого, источник волны (авто, коллекция, Яндекс, VK), выбор плейлистов, участие записей вне плейлистов, режим файлов на устройстве и видимость сервисов. Запрос жанров/исполнителей применяется к поиску новинок. Выбор плейлистов и офлайн-фильтр относятся к подборкам коллекции; персональная выдача сервиса определяется его аккаунтом.

## VK Музыка

Отдельная полка «Из твоей VK Музыки» читает персональную страницу `audio?section=explore` через сохранённую веб-сессию. Используется существующий сборщик данных сервиса; результат приходит отдельным сигналом и не смешивается с поиском. Есть подключение, обновление, ограниченный список, кэш 30 минут, воспроизведение по записи и целиком. Выход очищает выдачу. Проверка на фикстуре подтверждает маршрутизацию, кэш и выход; живая выдача аккаунта здесь не проверена.

## Яндекс Музыка

Блок Яндекса получает персональную цепочку `rotor/station/user:onyourwave/tracks`, а не результаты текстового поиска по исполнителю. При наличии сохранённой веб-сессии запрос выполняется в профиле сервиса с его заголовками. При наличии только OAuth-токена используется запрос к `api.music.yandex.net`. Кнопка «Подключить» открывает существующий вход в Яндекс; после входа выдача запрашивается снова. Для воспроизведения через страницу сервиса нужна веб-сессия; при необходимости открывается вход.

Ответ преобразуется в ограниченный список уникальных доступных треков. Ошибки входа, пустой ответ и недоступность сети показываются в блоке Яндекса. Локальная подборка не выдаётся за ответ сервиса. Последняя успешная выдача хранится в памяти 30 минут; «Обновить» запрашивает новую. При выходе выдача очищается, запоздавшие ответы OAuth игнорируются. Остановка или выбор другой музыки отменяют ожидаемый автозапуск волны. Произвольные поля аккаунта и токены не попадают в карточки.

«Включить волну» запускает рекомендации Яндекса, если аккаунт подключён; иначе — локальную подборку дня. Онлайн-очередь поддерживает переключение вперёд/назад, выбор и удаление записей. После конца порции запрашивается следующая; последние 50 ID передаются как `queue`. Получение аудио использует существующий механизм сервиса и не сохраняет временные ссылки в базе.

API Яндекс Музыки не имеет стабильного публичного контракта для этой интеграции. В этой среде живая проверка не выполнена: нет DNS-доступа из процесса, а страница Яндекса, открытая инструментом просмотра, сообщает о недоступности региона. Автоматические проверки подтверждают поведение клиента на ответах-фикстурах, а не доступность сервиса или подписки конкретного аккаунта.
