Написать приложение локального музыкального плеера для практика:

- Стек:
    * Qt 6.12 что здесь есть
    * WPF применяя qml формы
    * sqlite3 для хранения данных песен, откуда подгружались
    * исполнить согласно снимку EDM-модели

Задача: построить локальный музыкальный плеер который позволяет функционировать плеер прослушивания музыки на hyprland (linux), windows, android - позволяющая импортировать с яндекс музыки, ютуба, спотифая, вк музыку воруя нагло, кешируя музыку с выбором сохранения формата (сжатие легкое. без сжатия, полное сжатие с потерей качества звука). организовать чтобы музыку можно было экспортировать с плеера перенося на другое устройство легко. Реализовать удобный плеер в первую очередь для пользователя, сделать поиск музыки в интернете через доверенные источники для установки и локального использования кроме импорта с этой музыки, сделать систему рейтинга музыки, качества звука файлов, сделать систему предложений музыкального вкуса полноценно в зависимости прослушанных аудиотреков пользователя.
