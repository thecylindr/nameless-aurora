# NameLess Aurora

Локальный музыкальный плеер на C++20 / Qt 6.12 / QML. Главный экран с «Моей волной», экран прослушивания с атмосферой из цветов обложки, собственная SQLite-медиатека и связь с NameLess UI.

Обновление: общий поиск YouTube / Zaycev.net / VK, настройка вкуса, фоновые сцены и компоновка окна. [Изменения и ограничения проверки](docs/discovery-scenes-and-panels.md).

Актуальные изменения: [раздельное прослушивание и скачивание, исправление названий VK и EQ](docs/listening-downloads-and-equalizer.md).

## Запуск

В текущем рабочем окружении:

```bash
~/nameless-aurora/scripts/run.sh
```

Исходники — `~/nameless-aurora`, сборка скрипта — `~/player/build/aurora`. Скрипт собирает приложение, если исполняемого файла ещё нет. Для пересборки после изменения исходников:

```bash
cmake -S ~/nameless-aurora -B ~/player/build/aurora -G Ninja -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build ~/player/build/aurora --parallel 4
ctest --test-dir ~/player/build/aurora --output-on-failure
```

В Qt Creator открывайте `~/nameless-aurora/CMakeLists.txt`; конфигурация Desktop / Debug использует `~/nameless-aurora/build/Desktop_Debug` и Unix Makefiles. CMake-кэш привязан к расположению исходников. Если проект перенесён из другой папки, пересоздайте его:

```bash
cmake --fresh -S ~/nameless-aurora -B ~/nameless-aurora/build/Desktop_Debug -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Debug
```

Нужны Qt 6.12: Core, Gui, Widgets, Qml, Quick, QuickControls2, QuickShapes, ShaderTools, Sql с драйвером QSQLITE, Multimedia, Network, Concurrent, WebEngineQuick; на Linux также DBus. Тесты используют Qt Test (`-DBUILD_TESTING=OFF`, чтобы собрать только приложение). FFmpeg (`ffprobe` и `ffmpeg`) читает теги и встроенные обложки. Доступность кодеков воспроизведения зависит от сборки Qt Multimedia.

Ярлык для лаунчера NameLess UI и команда `~/.local/bin/aurora` устанавливаются без прав root:

```bash
~/nameless-aurora/scripts/install-desktop.sh
```

## Своя музыка

На главной — «Добавить музыку». В медиатеке — «Файлы» и рекурсивное сканирование «Папка». Можно перетащить аудиофайлы в окно. Поддерживаются MP3, FLAC, WAV, OGG, Opus, M4A, AAC, WMA и AIFF, если их декодирует Qt.

Файлы копируются в выбранную папку медиатеки; по умолчанию `~/Music/Aurora Player`. При совпадении имени и размера сравнивается SHA-256: разные файлы сохраняются с суффиксом, повторный импорт того же файла пропускается. Удаление записи из медиатеки сохраняет аудиофайл на диске.

Поиск работает с кириллицей без учёта регистра. Есть сортировка, любимые треки, оценки 0–5 и плейлисты. В меню `⋯` трека можно добавить его в плейлист или очередь, привязать аудиофайл, открыть исходную ссылку или загрузить доступное аудио. Кнопка `+` в боковой панели создаёт плейлист; на телефоне — меню `⋯` коллекции. Выбор коллекции на узком экране доступен над списком треков.

«Моя волна» собирается из доступных локальных файлов с учётом оценок, прослушиваний, исполнителей и пропусков. Это подборка из собственной медиатеки; сетевой каталог рекомендаций отсутствует. Очередь хранит ID треков и не сбивается поиском или сортировкой. В статистику попадает время воспроизведения, а перемотка не добавляет прослушанные минуты.

## Перенос из сервисов

На странице «Импорт музыки» выберите обычный профиль браузера или оставьте автоматический поиск. Нажмите «Забрать из VK» / «Забрать из Яндекса»: Aurora прочитает уже сохранённую сессию этого сервиса, откроет вашу коллекцию в фоновом браузере, запишет треки в SQLite и автоматически поставит доступное аудио на загрузку. Новое окно и повторный вход для действующей сохранённой сессии не нужны. Для отдельного плейлиста или альбома вставьте ссылку и нажмите «Перенести плейлист в плеер».

Сессии читаются из обычных профилей Brave, Chrome, Chromium, Яндекс Браузера, Firefox, Edge, Opera и Vivaldi на Linux, а также найденных профилей Flatpak/Snap. Читается снимок SQLite вместе со свежими WAL-транзакциями работающего браузера. Из базы выбираются cookies только выбранного сервиса; чужие домены не расшифровываются. Для Chromium используются форматы и системные хранилища ключей из установленного yt-dlp, для Firefox читается база cookies. Личный профиль не изменяется и не запускается с отладкой. Временные данные передаются через канал дочернего процесса, значения cookies в журналы не выводятся.

Фоновый Chromium работает с копией cookies в собственном профиле `service-browser/local-vk` или `service-browser/local-yandex` внутри каталога данных Aurora. Для Яндекса читаются JSON-ответы коллекции и полного плейлиста, недостающие метаданные запрашиваются через API. Для VK читается страница и состояние её проигрывателя. Сохраняются названия, исполнители, длительности, источник и порядок. `vk.com` и `vk.ru` поддерживаются. Подключение, чтение страницы и получение ссылки имеют сроки ожидания и отмену. После операции страница выгружается, неиспользуемый браузер закрывается.

Для VK читаются современные строки `MusicTrackRow` и состояние плейлиста самого сайта; при необходимости запрашивается полная загрузка списка через проигрыватель VK. Пустой старый контейнер не скрывает новый список. Если страницу не удалось распознать, Aurora отличает это от явно пустой коллекции и сохраняет отчёт в `diagnostics/import-vk.json` внутри каталога данных приложения. В интерфейсе появляется «Открыть отчёт импорта». Отчёт содержит адрес без параметров и счётчики структуры, без cookies и HTML.

В разделе «Отдельный вход / сбросить сессию Aurora» сохранён запасной ручной вход. Он нужен только при явном выборе этого способа; основной перенос не открывает пустой профиль. Там же можно удалить сохранённую сессию Aurora, не выходя из аккаунта в обычном браузере. Системный keyring должен быть доступен текущему пользователю; если сервис отвергает cookies, приложение сообщает об этом, не открывая новое окно автоматически.

Аудио берётся из доступного веб-проигрывания выбранного сервиса: прямой файл загружается через Qt Network, обычный HLS обрабатывает FFmpeg. Другой источник выбирается явно; исходная ссылка импорта остаётся у записи. Файл проверяется через ffprobe; если известна полная длительность и сервис отдал короткий фрагмент, он не добавляется как полный трек. Повтор запрашивает новую ссылку. Временные ссылки не записываются в SQLite и переносимый экспорт; cookies аккаунта не пересылаются на CDN. Поддержка защищённых потоков не реализована.

Загруженное аудио привязывается к исходному ID: оценки, плейлист и история сохраняются. Уже скачанные файлы отмечаются «В плеере». Записи без аудио можно также связать с локальным файлом через меню трека.

YouTube / YouTube Music используют ссылку на плейлист и `yt-dlp`. Файловые способы остаются в блоке «С устройства»: TXT (`Исполнитель — Название`), CSV (колонки `title`, `artist`, `album`, `url`), JSON с массивом `tracks`, переносимая медиатека Aurora. Для файлов без исходной ссылки загрузка из сервиса недоступна; метаданные сохраняются в коллекции.

Живые сайты могут менять разметку и способ выдачи аудио. Результаты исследования настоящего профиля Brave, включая ответы 8/24 трека и транспорт `encraw`, описаны в [docs/browser-import-investigation.md](docs/browser-import-investigation.md). Результаты проверок и ограничения среды перечислены в [docs/validation.md](docs/validation.md); успешная локальная сборка не заменяет проверку входа в реальный аккаунт.

## Загрузка аудио

«Найти аудио» автоматически ищет в последнем выбранном источнике. Результаты
ненадолго кэшируются, ввод запроса запускает новый поиск после короткой паузы.
Для Zaycev добавлен прямой JSON-поиск с браузером как запасным способом.
VK получил отдельное чтение страниц полного списка с учётом общего размера
и следующего смещения. [Изменения и границы проверки](docs/adaptive-sources-and-vk-pagination.md).

Загрузки доступны в общей панели над плеером на любом экране. У треков без
файла есть «Докачать», а при ошибке — выбор другой записи из YouTube,
SoundCloud, Zaycev.net, Hitmo или по прямой ссылке. Файл привязывается к исходному
треку с сохранением оценок, истории и плейлистов. Добавлены редакторы трека и
состава альбома, локальное сохранение обложек, аудиоиндикация и таймер сна.
Поведение источников и ограничения проверки описаны в
[docs/downloads-and-library.md](docs/downloads-and-library.md).

Дополнительно доступен поиск публичных MP3 в Internet Archive и ссылка на
отдельную запись Bandcamp. При включённом автоподборе проверяются YouTube и
SoundCloud; дополнительные сайты включаются отдельно в настройках импорта.

Настройки разделены на оформление, звук и библиотеку. EQ в нижней панели
открывает настоящий 10-полосный эквалайзер с пресетами, предусилением и запасом
громкости. Есть карточки палитр и предпросмотр атмосферы. Нижняя панель получила
компактную громкость, а очередь загрузок — ограниченную ширину на desktop.
[Последние изменения и границы проверки](docs/studio-update.md).

[Оптимизация анимаций, метеоры и замеры CPU](docs/animation-performance.md).

[Бонсай вокруг обложки, реакция корней на бас и готовность Windows/Android/iOS](docs/bonsai-and-platforms.md).

Очередь теперь плавает над страницей, не сдвигая её содержимое. Атмосфера
меняет палитру и форму под текущий трек; силу реакции и импульсы на ударах
можно настроить в оформлении. Переработана вкладка библиотеки и обложки
без изображения. [Текущее обновление](docs/floating-player-and-atmosphere.md)
проверено только компиляцией, согласно запросу пользователя.

Вкладка «Поиск YouTube» находит до 10 результатов по исполнителю или названию. Результаты сначала показываются без выбора; отметьте нужные треки перед загрузкой. Поиск требует установленного `yt-dlp` и доступа к YouTube.

Ниже на странице импорта — предпросмотр треков по ссылке, выбор качества (исходное аудио, MP3 192 или 128 kbps), очередь загрузок, отмена, повтор и проверка свободного места. Для VK/Яндекса нужны установленный Chromium-браузер, Python 3 и FFmpeg; зашифрованные cookies читаются модулем yt-dlp. Для YouTube/Spotify также нужны загрузчики. Менеджер приложения устанавливает `yt-dlp` и `spotdl` в собственное Python-окружение в каталоге данных Aurora; глобальные пакеты не меняются. Также можно использовать команды из `PATH` или указать пути в настройках.

```bash
~/nameless-aurora/scripts/run.sh --setup-tools
~/nameless-aurora/scripts/run.sh --check-tools
```

«Обновить» устанавливает актуальные `yt-dlp[default]` и `spotdl<5` в окружение Aurora. «Проверить» действительно запускает инструменты, включая `ffmpeg -version` и `ffprobe -version`; наличие файла само по себе не считается готовностью. SpotDL нужен только для Spotify. `--check-tools` печатает JSON с версиями и готовностью без открытия интерфейса. Предпросмотр YouTube читает плоский список вместо последовательной загрузки метаданных каждого видео; его можно отменить, а превышение срока ожидания сообщается отдельно от аварии процесса.

Если Node.js есть в `PATH`, он автоматически разрешается загрузчику для обработки YouTube. Доступность конкретной ссылки определяется загрузчиком, аккаунтом и ответом сервиса. Аккаунты VK/Яндекса подключаются в Aurora; загрузчики YouTube/Spotify работают отдельно. Списки TXT/CSV/JSON и локальные файлы работают без сетевых загрузчиков.

## Экспорт на другое устройство

В медиатеке откройте `⋯` → «Экспорт с аудиофайлами» и выберите папку. Aurora создаст в ней отдельный каталог с:

- `audio/` и `covers/`;
- `aurora-library.json`: относительные пути, метаданные, источники, оценки и состав плейлистов;
- `library.m3u8`: список доступных файлов для других плееров.

Можно экспортировать всю коллекцию, любимые треки или один плейлист. Записи без файла сохраняются как метаданные, а итог сообщает их количество. Копирование экспорта выполняется в фоновом потоке.

Перенесите всю папку на другое устройство, затем выберите в Aurora «Импорт музыки» → «Медиатека Aurora» → `aurora-library.json`. Файлы скопируются в новую медиатеку, оценки и порядок плейлистов восстановятся. Импорт проверяет относительные пути и наличие файлов перед изменением базы. История прослушиваний остаётся на исходном устройстве.

Также доступен экспорт списка в TXT.

## Атмосфера и оформление

В настройках — шесть палитр: Аврора, Лагуна, Тёплый вечер, Сакура, Полночь и NameLess UI. Есть свой цвет акцента, три варианта сферы (Сияние, Орбиты, Поток), интенсивность свечения и отключение движения. Всё применяется сразу и сохраняется между запусками.

Сфера рисуется одним GPU-шейдером: объёмное освещение, текучее сияние, орбиты и частицы, мягкая реакция на курсор. При воспроизведении движение ускоряется; это декоративная анимация, не анализатор спектра. На экране прослушивания оттенок берётся из обложки. Частота обновления ограничена 30 кадрами/с при воспроизведении и 15 в паузе; скрытые страницы и свёрнутое окно останавливают обновления.

При программном рендеринге сфера использует кешированную текстуру 256×256: движение меняет только её положение и поворот, без перерисовки геометрии каждый кадр. Фон также кешируется. В локальном программном замере расход CPU при движении снизился более чем в четыре раза; условия и результаты приведены в [docs/validation.md](docs/validation.md).

## NameLess UI и управление

На Linux Aurora публикует MPRIS: `org.mpris.MediaPlayer2.aurora` (дополнительные экземпляры получают суффикс). Медиавиджет Quickshell видит название, исполнителя, обложку, длительность, позицию, громкость, повтор и перемешивание; поддерживаются Play/Pause, Next/Previous, Seek, Raise и Quit. Работает `playerctl --player=aurora play-pause`.

В настройках оформления выберите «NameLess UI», чтобы синхронизировать акценты. Они читаются из `~/.config/hypr-themes/themes/` и палитры, выбранной в `${XDG_STATE_HOME:-~/.local/state}/hypr-theme/current`. Изменения отслеживаются автоматически. Без NameLess UI используется палитра Aurora. Рабочие конфиги оболочки приложение не изменяет.

| Клавиши | Действие |
|---|---|
| Пробел | Пауза / продолжить (вне текстового поля) |
| Ctrl + ← / → | Предыдущий / следующий трек |
| Ctrl + O | Добавить файлы |
| Ctrl + F | Поиск |
| Ctrl + N | Создать плейлист |
| Ctrl + L | Экран прослушивания |
| Escape | Закрыть экран прослушивания |

## Данные и платформы

База — `QStandardPaths::AppDataLocation/library.sqlite3`, на обычном Linux: `~/.local/share/Aurora/AuroraPlayer/library.sqlite3`. Настройки — `~/.config/Aurora/AuroraPlayer.conf`. Старая однотабличная база мигрирует в транзакции с сохранением ID, оценок и статистики.

Схема включает 7 таблиц: `artists`, `albums`, `sources`, `tracks`, `playlists`, `playlist_tracks`, `listening_events`, а также представление `track_details`. Структура и запросы описаны в [docs/database.md](docs/database.md).

Сборка и автоматические проверки выполнены для Linux / Qt 6.12. Компактный интерфейс проверяется в Linux-окне 390×760. Windows-сборка и APK в этом изменении не выпускались. Импорт из сервисов рассчитан на desktop-браузер; Qt WebEngine служит запасным вариантом. Для Android нужны отдельный веб-компонент, интеграция SAF и загрузчики; эта сборка APK не поддерживает.

Проверка запуска, декодирования и QML без звукового устройства:

```bash
QT_QPA_PLATFORM=offscreen ~/nameless-aurora/scripts/run.sh --smoke-test
QT_QPA_PLATFORM=offscreen ~/nameless-aurora/scripts/run.sh --smoke-test --import /path/to/track.mp3 --screenshot /tmp/aurora.png
```

Тесты используют временные базы и файлы: проверяют миграцию и её откат, связи и каскады, кириллический поиск, парсеры списков, повторный импорт и коллизии имён, очередь после фильтрации, учёт времени и перенос медиатеки с проверкой путей. Проверка запуска завершается ошибкой при предупреждениях QML.

Результаты проверки и скриншоты: [docs/validation.md](docs/validation.md).

Главная с подборками на день, три дня и неделю и интеграция «Моей волны» Яндекса: [описание и проверка](docs/home-recommendations.md).
